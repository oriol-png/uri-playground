Tools

Atomic, deterministic things an agent can do — no judgment. Named by outcome, not by object. Each tool carries its own permission scope (read / write / destructive); an agent's reach is the sum of its tools' scopes.
Permissions live here. There's no separate guardrail layer. On top of each tool's scope, an agent always defers to your existing Abacum permissions — it can never do something the person running it couldn't do themselves.
