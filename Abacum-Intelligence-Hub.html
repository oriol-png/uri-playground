Chats

Conversations with Abacum Intelligence. A chat is the manual Trigger — the agent runs because you asked.

Agents

A reasoning unit: instructions + a set of Tools + Context + scope. The chat orchestrator is the default Agent. Saved configurations live in the library as Agent templates you clone to start. Each agent carries its own Trigger.

Tools

Atomic, deterministic things an agent can do — named by outcome. Each tool carries its own permission scope; an agent's reach is the sum of its tools' scopes.

Permissions live here. There's no separate guardrail layer. On top of each tool's scope, an agent always defers to your existing Abacum permissions — it can never do something you couldn't do yourself.

Context

What an agent can see and ground on. Each type is independently grantable, so this screen also answers "what does this agent know, and what is it blind to?"

Custom uploads

Customer-provided context. Upload docs, policies or sheets to ground agents on knowledge that isn't already in Abacum.
